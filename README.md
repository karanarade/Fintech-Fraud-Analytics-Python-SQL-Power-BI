# Fintech Fraud Analytics Dashboard

An end-to-end FinTech Fraud Analytics project focused on analyzing financial transactions, identifying fraud patterns, and generating actionable business insights using Python, SQL, MySQL, and Power BI.

## 📊 Dashboard Preview

![Fintech Fraud Analytics Dashboard](Dashboard/fintech_fraud_dashboard.png)

## 🎯 Project Objective

The objective of this project is to analyze fintech transaction data, identify fraudulent transaction patterns, evaluate fraud risk across different dimensions, and present meaningful insights through an interactive Power BI dashboard.

The project follows an end-to-end data analytics workflow:

Data Cleaning → Exploratory Data Analysis → SQL Analysis → Data Modeling → DAX → Business Intelligence Dashboard

## 🛠️ Tools & Technologies

- Python — Data cleaning and exploratory data analysis
- Pandas — Data manipulation and preprocessing
- MySQL — Data storage and SQL analysis
- SQL — Data analysis and business queries
- Power BI — Interactive dashboard and visualization
- DAX — KPI calculations and analytical measures
- Power Query — Data transformation
- Git & GitHub — Version control and project documentation

## 💡 Key Business Insights

- Fraud transactions represent approximately 1.80% of total transactions.
- UPI contributes the highest number of fraudulent transactions due to its high transaction volume.
- Different payment methods show different fraud-risk levels.
- State-wise analysis helps identify regions requiring closer monitoring.
- Monthly trend analysis helps track changes in transaction and fraud activity.
- High-value fraudulent transactions can be identified for further investigation.
- The dashboard provides a centralized view of transaction activity and fraud risk.
